# 当前协议：纯动作模仿预热 4000 epoch

使用 `run_local_simtoolreal.sh bc`。旧 `warmup` / `train` 入口是 SAPG 奖励训练，
不属于本次协议。BC 不创建 SAPG Runner 或 central critic，不计算 PPO、GAE 或
任务奖励梯度。actor 的未使用 value head 和 sigma 冻结，保存时逐项检查未变化。
完成后只保存 actor 初始化并退出，后续 critic 校准和联合 SAPG 需要另行启动。

数据来自 accepted.json 的 100 条已验证空间变体，全部用于模仿，不留泛化验证集。
观测由本地复制的 SimToolReal 原生 Isaac Sim 环境生成：140 维、无 progress；
网络沿用原版 1024 LSTM、MLP 和六组系数嵌入，动作是原版机械臂增量与手部绝对动作。
6 个 block、每组1364环境仅用于初次采集。缓存只保留前100个环境，每条轨迹一次；
其余副本不会虚增样本量。BC 对六个系数 ID 轮换监督，每6轮覆盖全部ID。

源控制是100Hz，原版控制是60Hz，且机械臂每步有效最大增量约0.0025rad。
不能仅以100→60Hz插值解决。采集器分段重定时所有源控制途径点，反解原版动作，
逐步校验实际 native EMA 输出；关节目标内缩关节范围的0.1%，避免手部EMA有限步
无法到达精确边界。审计文件记录修正幅度，当前100条约174→5460步，最大目标修正
约0.0021rad。重定时不保持原接触动力学，也不证明任务成功。

采集阶段特例：按示范初始化机器人和物体，关节初速度/物体速度置零；固定原版平均
桌高；关闭动作延迟、观测延迟、对象状态噪声、关节速度噪声及随机外力；固定每条
轨迹最终目标，屏蔽中途done与奖励/成功驱动的目标重采样，保持整段动作标签连续。
物体根坐标经过现有角点标定的重心修正，并整体上移0.53m。机器人PD、有限effort、
资产、碰撞、原生动作处理、120Hz物理和60Hz控制保持本地原版适配设置。
上述采集特例只作用于采集实例，不改vendor文件，也不用于后续正式任务。

BC 学习率1e-4，Adam，固定log_std=-2，序列16步、前缀burn-in16步，梯度裁剪1。
**一个epoch是完整遍历所有缓存帧一次**，不是一次梯度更新，也不是环境step。
没有早停，运行恰好4000轮。按当前缓存每轮约54.6万监督帧，4000轮约21.84亿监督帧；
训练时长应以实际BC吞吐量估计，不能套用SAPG的环境FPS。

W&B只上传BC标量（loss、epoch、优化器更新数、AMP跳过数、耗时），不上传模型、
数据或视频。没有critic loss或reward训练损失；视频评估的原版reward分项均以eval/命名记录，
另存videos/*.metrics.json，仅用于诊断。每100轮保存actor_init.pt及优化器状态，
第1轮、每100轮和最后一轮另起6环境的原版任务评估，保存本地300帧视频。评估使用原版
随机机器人初始化/延迟/噪声与配对轨迹物体初始化，因而比teacher强制初始化更难；
视频只是闭环诊断。不要以BC loss下降替代target-reaching成功率验证。

输出：native_bc_dataset.npz、retiming_audit.json、teacher_rollout.json、
stage_contract.json、bc_progress.jsonl、actor_init.pt、bc_optimizer.pt、videos/、completed.json。
actor_init.pt 保留未训练的兼容value head，但后续critic必须重新初始化；不能直接把
bc_optimizer.pt 当成SAPG优化器状态恢复。
