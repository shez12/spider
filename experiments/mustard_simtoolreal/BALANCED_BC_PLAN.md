# 抓取分布均衡实验（2026-11-03）

目标：在不改原版 actor 观测、动作和 LSTM 的情况下，验证重加权是否改善抓取与 target reaching 热启动。
现有 SAPG 继续运行，不用新 BC 覆盖它的 actor 或 critic。

## 1. 固定证据和预算
- 数据：classified_20261102_v2/selected，503 条已通过原生动作验证的示范。
- 初始化：bc_carry200/actor_init.pt，两个实验相同权重、归一化统计和随机种子。
- A：原始逐有效帧 BC；B：温和的初态/抓持构型分组重加权。
- 各200轮，carry LSTM，16步截断，128条/批，LR=1e-5；同样的帧访问、优化器更新尝试次数和条件ID轮换。保留原AMP；分别记录溢出跳过次数，超过0.1%则中止检查，不能宣称成功更新次数完全相同。
- 不把200轮微调结论外推成“从头4000轮的最优配比”；先验证低成本增量收益。

## 2. 审计与权重
- 记录初始物体局部Z轴方向，分向上、侧向、向下三层（不是人工抓法标签）。
- 从首次连续30步满足抬升/掌物距离/指尖距离/速度代理的窗口提取抓持特征。
- 各初态层内聚类：归一化手关节、物体系下的掌物向量与指尖相对位置；合并过小组，防止异常稀有样本被放大。
- 目标轨迹质量：50%均匀轨迹 + 50%均匀有效分组，再类内均匀轨迹。
- 除以轨迹有效长度转换为逐帧权重；限制最大/最小权重比，归一化全库平均为1。
- 保留全部轨迹时间顺序、全部有效帧，补齐帧权重为0；不同时加入阶段权重，避免混淆因果。
- 输出每组样本数、帧数、实际损失质量、阶段占比、代表案例与数据SHA256。聚类是构型代理，需结合闭环结果解释。

## 3. 实现与验证
- 重加权默认关闭，不改变现有BC行为；校验candidate ID、长度、数据SHA256、有限正权重。
- 单元测试：padding排除、质量归一化、上限、ID错配拒绝、全1权重等价原损失。
- 2轮短测确认模型更新、critic/sigma/输入统计不变、有效帧数一致，再开始200轮A/B。
- 各实验独立目录与W&B记录，不覆盖旧结果。监测正式SAPG和实验进程，避免同时叠加多项GPU评估。

## 4. 配对闭环评估
- 比较原始初始化、A、B，确定性leader动作；同一随机种子、同一物理初态与目标。
- 示范初态：全部503条，测抓持、首次目标到达，并按分组报告。
- 当前训练分布：随机示范机器人初态 + 原版物体/桌高/首次目标采样，至少256个固定案例。
- 已保存的14个自然掉落状态：单独报告恢复抓持，不当作无偏总体成功率。
- 每例16秒；冻结目标、关闭自动reset用于同初态固定窗口诊断；报告为诊断成功率，不冒充原版50目标回合成功率。
- 抓持使用连续30步几何代理；到达使用原生tolerance参数0.075 × keypoint_scale 1.5，即缩放角点距离0.1125m，累计10步（原版force_consecutive=false）；另记连续步数。保存逐例结果、配对差与不确定性。
- 视频使用原版任务生命周期另行录制；若诊断与原版闭环矛盾，以原版任务表现为准。

## 5. 决策与后续
- 首先检查少数组收益是否以显著损伤多数抓法为代价；只看总体MSE不能选模型。
- 若B在同预算下改善闭环结果且未明显损害示范技能，用第二个训练seed确认，生成可复现推荐命令。
- 若无改善，保留A/B证据，不强行宣称均衡有效；根据逐组失败决定是否另做阶段权重消融。
- 若原版随机reset/掉落恢复仍几乎全失败，标记覆盖缺口，导出失败状态需求；已有轨迹没有成功恢复时，不以重复采样冒充补齐数据。
- 完成标准：审计、实现、短测、同预算对照、配对闭环结果和下一步决策均落盘。任何长期训练启动不等于实验完成。
