# 用已有轨迹加速训练：重新规划（2026-11-11）

目标不变：用前处理管线得到的轨迹，让"从原生随机起点学会操作"更快、更稳。本文只给方案，没有启动任何训练。

## 1. 手上的轨迹里到底有什么（已核对）

| 数据 | 数量 | 内容 | 所在环境 |
|---|---|---|---|
| 管线有效轨迹 | 478 条，来自 10 个原始示范（4 个各 100 条，1 个 65 条，其余 1–9 条） | 每条约 174 步：关节目标、关节角、关节速度、瓶子位姿；另有手腕、4 个指尖、瓶子的参考轨迹 | MuJoCo，KUKA + Sharpa **右手** |
| 右手状态库 v4.1 及其左手镜像 | 3684 / 3354 个状态 | 只有状态，没有动作 | Isaac 右手 / 左手 |
| MPPI 轨迹 | 原尺寸 144 组（真离桌 20 组），小瓶 128 组（真离桌 70 组） | 状态 + 动作，从原生起点滚出 | Isaac 左手（训练环境） |

- 示范的内容是"伸手 → 抓住 → 抬起"：10 个源里瓶子被抬高 25–38 cm，最大转动 9–64°。**没有"把瓶子转到任意目标朝向"的内容。**
- 所以这批轨迹能加速的是抓起这一段。抓起之后的搬运和转向，示范里没有，只能靠改任务或另加课程（见第 4 节 C）。

## 2. 之前的用法为什么没起作用（对照文献）

我们一直用的是一种做法：把轨迹切成状态，按固定比例（原生 50% / 库 50%）混进重置。

| 文献里这类方法成立的条件 | 我们的做法 | 实测后果 |
|---|---|---|
| 起点要随学习进度**往回退到原生起点**：学会一段，起点就往前挪一段（Salimans & Chen 2018；DemoStart 2024） | 比例固定，从不退 | 镜像库 393M 帧：库内"接近"类起点抓起 89%，原生起点 1.0% |
| 库内状态要和原生起点**连得上**（同一条轨迹上的早晚时刻） | 镜像库的手臂关节离原生起点中位 3.2 rad，中间没有任何状态 | 同上 |
| 要**剔除太容易 / 不自然的状态**。DemoStart 专门指出：示范里抓得不稳的状态会让策略去学"补救坏抓握"，并且学会抓之后就不该再从已抓住的状态出发 | 抓住 / 抬起类一直占 30% 的回合 | 带训练同款干扰力时，库内离桌状态 3 秒后只剩 41–67% 还握着 |
| 示范给的是**所有回合**的起点或奖励（Human2Sim2Robot 2025；PGDM 2023） | 原生回合里没有任何来自示范的信号 | 小瓶：带库的两个 seed 到 196M 帧原生抓起 0.2–0.4%，从零同帧数日志抬起 42% |

另一条路是 BC 预训练再接 RL（DAPG 2018；Nair 等 2018）。它要求示范的观测和动作就在训练环境里。我们的动作在右手 MuJoCo 环境，训练在左手 Isaac 环境；右手场景里试过的 BC + 状态库在原生起点是 0/128。

**结论：** 问题不在"轨迹没用"，而在两点：一是示范和训练环境不是同一个本体和场景，关节空间的状态搬不过来；二是状态重置没有做成往原生起点退的课程。

## 3. 文献里和我们最接近的做法

- **Human2Sim2Robot**（Lum 等，CoRL 2025；同样是 KUKA 机械臂 + 多指手）：从一段人手示范只取两样——瓶子位姿轨迹（当奖励）和**一个预抓取手姿**（当所有回合的起点）。消融里，从默认姿态起步、或手离物体 20 cm 起步都最差；从物体正上方起步也没收敛。即起点必须贴近物体，且手姿要对。
- **PGDM**（Dasari 等，ICRA 2023）：只给预抓取手姿 + 物体轨迹，不需要完整示范，50 个任务上不用逐任务调奖励。
- **从单条示范学 Montezuma**（Salimans & Chen 2018）、**DemoStart**（Bauza 等 2024）：从示范状态起步，起点随成功率自动往回退，最后回到原始起点。
- **JSRL**（Uchendu 等，ICML 2023）：前 h 步由一个现成的引导策略执行，之后交给学习策略，h 逐步减到 0。引导策略可以是脚本。
- **DexMachina**（Mandi 等 2025）：用一个逐渐衰减的虚拟力把物体带向目标，策略逐步接手。
- **DAPG**（Rajeswaran 等，RSS 2018）、**Nair 等 2018**：BC 预训练 + RL 时保留一个逐渐衰减的示范损失。
- **AMP**（Peng 等 2021）：只用示范状态（不需要动作）训练一个判别器当风格奖励。

我读了正文的是 DemoStart、Human2Sim2Robot、Salimans & Chen；其余只核对了摘要。

## 4. 建议的新方案

核心改动：**不再搬关节状态，只搬"手相对瓶子"的信息**（预抓取手姿、抓握时的指尖位置、瓶子轨迹）。这些量不受左右手、手臂构型、仿真器差异的影响。

### 第 1 步（不训练，约 1–2 小时）：在左手训练环境里，从原生起点按示范"相对瓶子"重放

- 对每个原生随机起点：按瓶子当前位姿，把示范的预抓取手姿（镜像到左手）变换过去，用手臂逆解（已有脚本，取离原生构型最近的解）移过去，再按示范合指、抬起。
- 量：多少比例的原生起点能抓起并真离桌。10 个源分别统计。
- 这一步决定后面走哪条路，并且一次产出三样东西：
  1. 贴着原生手臂构型的**预抓取状态**（瓶子位置服从原生分布，不是管线里的位置）；
  2. 一个**脚本引导策略**；
  3. 在训练环境里、从原生起点出发的**观测–动作示范**（以前要重跑管线、按天算才能得到）。

### 第 2 步（训练，每组约 1.3 小时到 300M 帧，GPU 空着时约 63k 帧/秒）

按第 1 步结果二选一，都保留原生起点评估口径：

- **A. 起点课程（首选，改动最小）：** 所有回合的手臂起点取"原生构型"和"预抓取构型"之间的插值，比例 s 从 1（贴着瓶子）开始；最近一段的抓起率过阈值就把 s 往 0 退一格，退到 0 就是纯原生起点。回合里不再放"已抓住 / 已抬起"的状态。依据：Human2Sim2Robot、Salimans & Chen、DemoStart。
- **B. 引导策略接力（第 1 步重放成功率 ≥ 约 30% 时可用）：** 每个回合前 h 步由脚本执行，之后交给策略，h 随抓起率减到 0（JSRL）。同时可以用重放成功的轨迹做 BC 预训练，RL 阶段保留衰减的示范损失（DAPG）。
- 对照：同一任务从零，同样 seed。主指标：原生抓起率到 50% 用的帧数，3 个 seed；从零的日志抬起到 50%：原尺寸 319M 帧、小瓶 291M 帧；原尺寸 3 次里有 1 次全程没学会。

### C. 抓起之后（示范里没有的部分，需要你定方向）

所有能抓起的组都卡在这里（首目标最高 0.3%，74–88% 的回合以掉落结束）。两个可选改法：

- **把目标改成示范里的瓶子轨迹**（抬到示范的终点位姿），不再是随机 6D 目标。这样整条任务都被示范覆盖（Human2Sim2Robot 的做法），但任务比 SimToolReal 原版窄。
- **干扰力课程：** 从 0 起步，随成功率加到原版强度。依据是这次的实测：同款干扰下抓握 3 秒保持率只有 41–67%。这一项和轨迹无关。

### 搁置

固定比例的状态库（MPPI 库、镜像库）、镜像后的关节状态和动作、右手场景的 BC。

## 5. 风险

- 第 1 步的重放可能成功率很低（Human2Sim2Robot 里"按物体重放"比 RL 低 55 个百分点）。即使这样，预抓取状态仍可用于 A。
- 手臂逆解已验证能解出镜像库的全部手腕位姿，但解出的构型离原生构型中位 0.9–1.2 rad，是否顺路可达要在第 1 步里看。
- 4 个大源占了 478 条里的 400 条，抓法实际主要来自 5 个示范。
- A 的课程只管"伸手到瓶子"这一段。如果从零慢的真正原因在合指和抬起，A 的收益会小；第 2 步的对照会直接显示。

01:40 的版本里"示范抓法从原生起点够不到"是算错了（逆解目标多加了一次基座偏移），已作废。修正并自检后的结果（`experiments/mustard_simtoolreal/demo_relative_grasps.py`，输出 `outputs/demo_relative_v1/`）：

| 项 | 数值 |
|---|---|
| 瓶子摆放 | 示范 10 个有效源里 9 个立着，1 个（第 2 源，65 条）宽面朝下躺着；随机起点 89% 宽面朝下躺着，6% 立着 |
| 有可行示范抓握位的随机起点 | 现有有效轨迹 37%；22 个原始示范的运动学参考全算上 60% |
| 抓握位离原生手臂构型（最大关节差） | 现有有效轨迹：p10 / 中位 / p90 = 0.44 / 0.76 / 1.14 rad；MPPI 抓握 0.3 rad |
| 手臂限速 | 0.15 rad/s，10 秒回合最多 1.5 rad；走到抓握位中位约 5 秒 |

- 约束（用户 02:30）：从完全随机状态抓起是必须的，其余过程都可改。
- 起点课程 A 对有示范可用的那部分随机起点可行：瓶子位姿始终来自随机起点，只有手臂从预抓取位逐步退回原生构型；其余起点保持纯随机起点。
- 覆盖面受瓶子朝向限制：每个示范只覆盖一段朝向。扩大覆盖要靠把躺着的第 4、9 源在管线里跑出有效轨迹。
- 仿真重放（示范按限速放慢后能否真的抓起）在补做。
