# Mustard 轨迹热启动与 SimToolReal SAPG：目标、现状和计划

更新日期：2026-11-04（Asia/Shanghai）。这是一次状态快照，后续进度以训练日志和阶段评估为准。

## 1. 实验目标

利用经过优化和仿真验证的 mustard 抓取轨迹，为 SimToolReal 的 target pose reaching 任务提供热启动，比较其是否能减少在线 SAPG 学习所需的交互量和时间。

训练路线为：

1. 用轨迹监督训练 actor，使其具备基本抓取和搬运能力。
2. 冻结 actor，使用环境 rollout 和任务奖励训练 critic。
3. 解冻 actor，以 SAPG 联合训练，逐渐适应原版随机初态和连续目标。

actor 的 BC 阶段模仿动作；critic 学习任务回报。解冻后 actor 也通过 SAPG 的优势估计优化任务回报，并非始终只模仿轨迹。

正式任务是 target pose reaching，目标数量上限保持50；轨迹用于初始化能力和提供经过验证的 reset 状态，不将正式任务改为按时间复现整条轨迹。保持原有观测，不加入轨迹 progress 观测。

最终需要证明的是原版随机初态下的目标完成、掉落后恢复，以及相对匹配基线的样本效率；熟悉示范状态下成功或混合训练奖励提高，均不足以证明热启动已经有效。

## 3. 当前环境和初始化

- 并行规模：6个SAPG block，每组1364环境，共8184环境。
- 原actor观测140维、动作29维，保持原网络与动作接口。
- 任务目标上限50，当前时限16秒。原版计算在目标成功后重置目标计时，因此16秒不应理解为整条50目标链的总时间。
- 原生分支采用原版物体位置、三维朝向、桌高和机器人初始化。
- 机械臂和手指均按以下公式初始化：

```math
q_0=0.9q_{default}+0.1q_{uniform(lower,upper)}
```

其中0.1是插值比例，不是±0.1rad；关节速度独立均匀采样于[-0.5,0.5]rad/s。直接调用vendor采样函数，控制器previous/current目标与采样q一致。

缓存分支恢复验证状态配套的机器人q/v、控制器目标、物体、桌面及目标状态，避免额外随机化破坏已有接触构型。

当前仍有实验性设置，例如16秒时限和混合reset；不能称为与原版环境完全一致。

## 8. tolerance课程规则

当前取消固定tolerance，采用原版乘法收紧规则，并避免缓存成功造成误导：

1. 距上次收紧至少3000个控制步，而不是3000epoch。
2. 只统计各环境最近完成且属于原版随机reset的回合；缓存reset和未完成过有效回合的环境不参与。
3. 平均每回合完成目标数达到3，tolerance乘0.9，最低0.01。
4. 表现不足时保持当前值，不回退放宽。

其他难度暂时保持，不同时缩短时限或改变reset分布。按目前原生回合的表现，暂不应触发tolerance收紧。

## 9. 后续执行计划

### 当前窗口：12300至16300轮

- 保持当前配置持续训练，检查数值、检查点、视频和W&B上传。
- 每500轮，用固定配对起点评估原生随机、示范附近、稳定抓持、接近目标及恢复状态。
- 分别记录初始持物、持续抓持、首次目标到达和成功前掉落；区分在线训练分布与固定评估结果。
- 优先观察原生随机初态和恢复状态能否出现稳定改善，不能以混合奖励或缓存状态成功替代。

### 窗口结束后的决策

如果原生/恢复表现改善：保留同一评估体系继续SAPG，让成功驱动tolerance课程。后续恢复更接近原版的时限等设置时，每次只提高一项难度，表现不足暂停推进，不回退。

如果仍无明显改善：优先补充“原生初态→可接近/可抓取状态”和“掉落→重新抓取”的桥接覆盖，避免仅增加已经成功抓持的状态或盲目延长训练。

桥接数据的具体方向：

- 从真实策略rollout采集未抓住、抓空、掉落后的物理状态，按物体朝向、相对手位姿和接触阶段分组。
- 用短片段恢复/局部优化或由易到难的物理reset连接到可抓取区域，减少重新优化完整长轨迹的需求。
- 新状态继续执行碰撞、稳定性、可恢复和控制器一致性审核。
- 若用于BC，需要匹配正确观测和可执行动作；只有状态缓存不能直接当成监督动作样本。
- 单独设置未用于训练的恢复测试状态，避免只改善缓存训练状态本身。

这些桥接扩充是下一步候选方案，尚未在本轮额外启动生成任务。
