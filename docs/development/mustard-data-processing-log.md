## 数据处理流程

1. **筛选源示范**：读取已发布轨迹，按原始任务去重；优先选择 Allegro 版本，缺失时使用其他已发布右手版本。其他数据集名称相近的 mustard 模型不混入。
2. **提取参考**：保存手掌位置与姿态、四指指尖位置、物体位姿。参考时间轴不延长，不做左右镜像。
3. **建立环境**：KUKA＋原生 Sharpa 右手；机械臂底座与桌面保持 53 cm 高度差，加入真实桌子盒体；机器人重力补偿为 1，物体为 0；无 extra hold。
4. **空间增强**：手和物体应用同一个平面刚体变换，旋转 ±10°、水平偏移 ±5 cm；保留高度、时间和手—物体相对交互关系。
5. **IK 与几何筛选**：检查初始对齐、跟踪、关节限位、桌面范围、机器人—桌面碰撞和手部自碰撞。确定失败者不进入 GPU 优化。
6. **GPU 优化**：MuJoCo Warp；原始 SPIDER 采样更新和代价函数；每条 512 个采样、最多 200 轮、收敛提前停止；不因 cost 小于 100 就停止。
7. **双重物理验证**：检查优化中选中的实际轨迹，以及重新初始化后的独立 GPU 重放。两次均通过才计为有效。
8. **保存并补足数量**：有效项保存轨迹、独立重放、验证报告、checkpoint、历史和视频；失败项不计数，按源继续补足，各组数量不相互替代。

方法溯源补充（2026-10-31核对实际产物）：另一世界模型工作流已为生产第18组配置反馈控制器pilot。其100条有效结果中，27条无reference_policy，73条带世界模型reference_policy；原采样更新、代价及双严格标准保留，但控制生成方式不同，不应把该组全部结果称为纯原始控制基线。其他组当前未配置该反馈policy。本跟进没有开启、关闭或改动该配置。空间增强uniform/adaptive隔离试验保持独立，不因此更改其原实验结论。

## 不变的有效标准

选中轨迹和独立 GPU 重放都必须满足：

- 物体位置 RMSE **＜ 3 cm**。
- 最终物体位置误差 **＜ 3 cm**。
- 最终物体旋转误差 **＜ 20°**。
- 机械臂—桌面、手—桌面及手部自碰撞最大穿透分别 **＜ 1 mm**。

碰撞几何审核基于保存的 10 ms 帧和源模型；不代表帧间连续碰撞保证。视频来自保存的实际 GPU 状态，不用 CPU 动力学重演代替。

## 已完成的实验与结论

### 同轨迹 MuJoCo / Isaac Sim 对照

2026-10-29 完成。同一条 mustard 候选、seed=0、512 个采样、固定 200 轮；两边保留原始 SPIDER 更新与代价函数，顺序执行，其他训练仍在运行。

- **MuJoCo Warp**：端到端约 **11.3 分钟**，最佳 cost **3.948**；位置跟踪良好，但最终旋转误差约 **20.3°**，未通过严格标准。
- **Isaac Sim / PhysX**：端到端约 **42.6 分钟**，最佳 cost **3.159**；最终旋转约 **14.4°**，但机械臂—桌面最大穿透约 **1.44 mm**，未通过严格标准。
- 当前 Isaac 适配实现耗时约为 MuJoCo 的 **3.76 倍**；两边本次有效数均为 0。
- 结论：继续使用 MuJoCo Warp 进行当前批处理。单条单 seed、共享 GPU 负载下的结果不能推广为所有 Isaac 场景的性能结论，也不能据此建立稳定有效率。

当前生成方式在 yaw ±10°、XY 各 ±5 cm 内独立均匀随机，不利用历史成功或失败反馈。检查已有候选发现不同源的可行区域明显不同：第 2 组目前 3 条成功集中在 Δx 约 -3.35～-3.00 cm、Δy 约 +3.93～+4.77 cm；第 10 组 4 条成功的 yaw 约 -9.95～-5.27°；第 18 组成功分布较宽，不宜强行缩小范围。成功样本仍少，以上是观察，不能视为完整可行域。

建议下一轮隔离对照使用“25% 全域探索＋75% 自适应提议”：始终保留全范围探索；有物理成功样本时在其附近提议，无成功样本时优先探索 IK 合格/几何误差较小区域。仅有 IK 合格不能当成物理成功标签。分别建模初始对齐、碰撞、跟踪及旋转失败，不能简单将所有失败视为同类。每个源独立学习，不跨源替代数量。

多样性保护：旋转和平移按各自原始范围归一化后检查候选间距；维持空间分箱覆盖，避免 100 条都挤在同一成功点附近。具体最小间距和覆盖指标需在试验中确定并记录。全部提议仍应用相同手—物体刚体变换，保持时间、高度和原有验证标准不变。
