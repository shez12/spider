# 空间增强采样隔离对照

启动时间：2026-10-30 16:25 左右（北京时间）。生产采样未替换。

## 设计

- 源组：2、10、18（已有不同分布的成功样本），8（长期零 IK 通过）。
- 每个源的均匀组、自适应组各 16 个新候选，共 128 个；候选预算相同，失败不补抽。
- 自适应组每 4 个提议槽中 1 个全域探索、3 个局部提议，即 25%/75%。
- 范围仍是 yaw ±10°、XY 各 ±5 cm；手和物体使用同一个变换，高度和时间不变。
- 历史反馈在实验前冻结并保存 SHA256，避免评估期间的未来标签泄漏。
- 有物理成功时围绕同源成功点采样；无物理成功但有 IK 合格时，只作为几何引导；全无通过时围绕几何必要条件误差较小的失败点提议，明确标为 near-miss，不能称作成功。
- 局部扰动标准差为 yaw 2.5°、X/Y 各 7.5 mm；越界采用拒绝重抽，不裁剪到边界。
- 没有反馈或难以满足间距时可退回全域提议，并明确记录 fallback；本次生成的计划没有发生 fallback。

## 多样性与公平性

- 距离定义为 `[yaw/10°, dx/5cm, dy/5cm]` 空间的欧氏距离。
- 与实验前已有有效点、同一试验臂中新候选的最小距离均为 0.1；不静默放松。
- 两个方法使用相同的间距保护，因此对照是“带相同多样性保护的均匀采样”，而不是完全无约束的独立随机。
- 保存 4×4×4 分箱覆盖、归一化最近距离和三个维度的跨度。候选覆盖与最终有效轨迹覆盖分别报告。
- 不因为局部采样提高有效率，就忽略覆盖缩小；本次第 2、10 组自适应候选占用的空间分箱少于均匀组，需要结合结果评估。
- 源组、两种方法按候选序号交错投递，避免一侧全部先跑；同一机器其他负载仍可能变化。

## 优化与验证

- 沿用原始 SPIDER 优化器、代价和更新，每条 512 个采样、最多 200 轮、收敛提前停止。
- 两侧均启用每 10 轮的严格双验证成功提前结束。
- 选中实际轨迹与独立 GPU 重放都要满足原有位置、旋转、碰撞标准。
- 继续使用当前共享的 8 个生产 GPU 槽和 8 个 IK 槽；实验自身最多 2 个 CPU worker、2 个 GPU worker，不使用其他训练的 2 个预留槽。
- 记录资源排队等待与实际计算耗时。各方法的 service-hour 指标是工作时间之和，不等同于独占机器的端到端墙钟速率；实验总墙钟也保存。
- 单源每臂 16 个候选只是 pilot，不能由少数成功推断稳定成功率或整体工期。
- 不将实验有效项自动计入生产清单，也不自动替换生产采样。
